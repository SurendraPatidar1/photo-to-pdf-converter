
# DSA Notes Automatic PDF Generator

## Run on Windows

Open Command Prompt in this folder and run:

```bash
pip install -r requirements.txt
streamlit run app.py
```

The browser will open the PDF generator.

### Sequence rule

The numeric prefix controls the PDF order:

001_Data_Structure.png
002_Classification.png
003_ADT.png
...
059_Radix_Sort.png
060_Complexity_Cheat_Sheet.png

You can upload all images individually or upload one ZIP.
